# RezaAdisanyoto.github.io

Website pribadi Reza Adisanyoto yang di-host melalui [GitHub Pages](https://pages.github.com/) dan dapat diakses di **[referfbby.me](https://referfbby.me)**.

## Struktur Repositori

```
.
├── index.html   # Halaman utama website
├── CNAME        # Custom domain (referfbby.me)
└── README.md    # Dokumentasi ini
```

## Pengembangan Lokal

Untuk melihat tampilan website secara lokal, buka file `index.html` langsung di browser atau gunakan server lokal sederhana:

```bash
# Menggunakan Python
python -m http.server 8000
```

Kemudian buka `http://localhost:8000` di browser Anda.

## Deployment

Setiap perubahan yang di-push ke branch `main` akan otomatis di-deploy melalui GitHub Pages ke domain **referfbby.me**.
